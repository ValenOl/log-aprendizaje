1 - Instale uv, que es una herramienta donde junta todas las dependencias y sub-dependencias,
con la versiona exacta de cada paquete, facilita el trabajo y organizacion del trabajo.

Solucionamos un problema que tiene Python y es que usa varias herramientas juntas,
 pip install, requirements.txt, python env. uv organiza todo en una herramienta.





2 - Con pyproject.toml definimos que dependencias necesita el proyecto. uv.lock contiene el arbol
 de dependencias y subdependencias que se van a instalar en las demas plataformas,
 garantiza que todo el equipo instale todo lo mismo.
 Eliminamos requirements.txt por que dejamos pyproject.toml. 
Si dejamos los dos se puede romper la sincronizacion del proyecto y crear problemas de
 inconsistencia.


3 - Hicimos dos commits por que cada commit tiene que conta una sola historia, mejor
organizacion. Cada mensaje explica cada cambio que se hizo. 




## Checkpoint
[x] PATH: Lista de carpetas en orden  donde la terminal busca el programa que vas a utilizar.
[x] Entorno Virtual: Pone venv/bin en el PATH asi cuando escribis python, la terminal encuentra el Python del
proyecto y no el del sistema. Ademas, el entorno virtual es para que cada proyecto tenga sus propias dependencias,
 configs, etc.
